🛒 ElectroMart – Online Electronics Store

📌 Project Overview

ElectroMart is an attractive and responsive online electronics catalog website developed using HTML5 and CSS3. It displays electronic products such as laptops, smartphones, headphones, smartwatches, wireless keyboards, and smart speakers.

The website provides product details, prices, discounts, comparison tables, and customer services.
